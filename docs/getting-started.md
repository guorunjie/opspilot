# 开源核心演示：快速开始

这是 Apache-2.0 授权的早期离线药房 Demo，全部经营数据均为合成数据。它不是完整 Foundation，也不能操作真实门店。

## 从源码启动

普通用户可直接使用 [dev.4 安装包](https://github.com/guorunjie/opspilot/releases/tag/v0.1.0-dev.4)，无需以下开发命令或 Node.js。Windows 安装后打开桌面或开始菜单中的“OpsPilot Open Core Demo”，不是旧商业版“OpsPilot”。macOS 当前提供 Apple Silicon 版本。安装包未配置可信发布者签名或公证；不要关闭系统安全检查。

需要 Node.js 24 或更高版本，以及 Git。下载依赖需要网络；安装完成后的 Demo 操作和模拟回读不访问真实平台。

```sh
git clone https://github.com/guorunjie/opspilot.git
cd opspilot
npm ci
npm test
npm start
```

当前锁定 Electron 42.7.0 和 electron-builder 26.8.1。Electron 可能在首次 `npm start` 时才下载运行时，因此首次启动也需要网络；依赖安装成功不等于运行时已经就绪。当前源码本机测试及桌面验收范围见[架构与阶段边界](architecture.md)；这不等于全新机器或生产环境验收。

具体范围见[验证记录](verification.md)。

## 完成一次经营演示

1. 点击“运行演示诊断”，查看今日重点，展开建议依据。
2. 点击“查看跟价预览”，核对商品、原价、目标价格、成本和估算毛利率。估算毛利不等于实际利润；成本未知不能当作零成本。
3. 核对无误后，勾选“我已核对本次商品、目标价格和毛利，仅确认模拟操作。”，点击“确认本次预览”。
4. 选择演示场景，再点击“执行模拟操作”。提交后还不能判断成功。
5. 点击“核对模拟平台结果”，查看每项目标价格和回读价格，以及验证结果和复盘。
6. 点击“复位演示”并确认，可回到初始合成数据。取消复位会保留当前记录。

以上是价格流程。`dev.4` 预览安装包及当前源码还提供下方“继续体验 · 库存与活动机会”（旧 `dev.2` 安装包不包含）：

1. 运行诊断后，查看库存或活动建议依据。
2. 点击“预览库存建议”或“预览活动建议”，核对目标变化。
3. 点击对应确认按钮，在弹窗中明确确认；取消不会授权。
4. 点击“执行库存模拟”或“执行活动模拟”。也可展开“异常场景”，选择一种异常执行，不能重复提交。
5. 点击对应“核对…模拟结果”，查看回读值与复盘。首次回读不可用时仍点击核对，不重新执行。

库存模拟把商品 C 的可售数量从 0 更新为 12，不代表实际采购或实物补货。活动模拟为商品 A 报名固定 ¥18 活动，不改日常标价，不代表真实活动上线。三条任务彼此独立，不能复用其他任务的确认；成本缺失提示仍不提供成本修改入口。

## 四种场景

| 场景 | 可以观察到什么 |
| --- | --- |
| 正常提交 | 提交后等待回读，逐项匹配后才显示模拟验证通过 |
| 提交后响应丢失 | 不重复提交，通过模拟回读确认目标状态 |
| 回读价格不一致 | 明确显示不一致，不报告成功 |
| 首次回读不可用，结果未知 | 首次显示 UNKNOWN；“再次核对（不重复提交）”仅读取，不重新执行 |

最后一种场景的第二次回读由合成夹具确定性恢复；真实平台不保证下次检查能够恢复。所有模拟验证均不代表真实平台验收。

## 重启与数据

会话保存在本地 SQLite。重启恢复已保存的预览、确认和执行记录，不会自动执行。已有确认以只读记录展示，不代表新的授权。演示复位让当前视图回到初始合成状态，不操作真实门店数据。

- **dev.4 新建数据库**：使用 v4/async-demo 标记，价格执行检查点与模拟目标分别持久化，再独立回读。确认复位切换到新会话，旧记录仍保存在数据库中；旧确认不授权新任务。复位不是安全擦除。
- **已有 v1/v2/v3 数据库**：继续使用原执行实现，不因安装 dev.4 自动迁移。旧 v1 任务可继续原流程，完成后明确复位才能体验库存与活动机会；仅价格存档为 v2，首次预览库存或活动后为 v3。旧引擎复位替换当前会话；不能据此认为已切换到异步引擎。

当前源码另提供[保留旧记录并开始新版演示](legacy-demo-upgrade.md)：默认取消，确认后旧记录只读保留，新任务重新诊断和授权。此入口不在 dev.4 或 dev.5 标签安装包中；不要删除旧记录来获取新演示。
- **兼容性与恢复限制**：旧程序不能读取 v4；不要覆盖安装旧版、删除字段或删除数据库来规避检查。显式迁移入口及强制中断后的遗留执行锁恢复入口尚未完成。如被阻止继续，保留记录并反馈，不要重复提交或手工解锁。

Windows 数据位于用户的 `AppData/Roaming/opspilot-open-core/offline-demo`。卸载候选安装版保留该目录。演示存档无效时停止加载并保留原记录；不要为了启动成功而直接删除存档。

Demo 不读取真实账号凭据、不启动生产调度、未接入生产 Connector。当前恢复保障覆盖本地模拟状态，不是生产连接器的分布式恢复保证。

## Windows 打包与反馈

开发者可使用 `npm run desktop:dist:win` 构建安装包，输出位于 `dist/core`。应用名称为“OpsPilot Open Core Demo”，与旧版 OpsPilot 区分；默认创建桌面和开始菜单快捷方式。构建命令不自动发布。

候选包尚未签名，不要绕过系统安全提示。macOS 打包命令为 `npm run desktop:dist:mac`，须在相应环境构建和验证；存在命令不代表已完成适配。正式下载资产及其验证状态以 GitHub Releases 为准。

遇到错误，请提供操作系统、版本、复现步骤和脱敏错误信息，通过 Issue 或 guorunjier@163.com 反馈。不要上传账号凭据、真实经营数据或未脱敏的存档。
