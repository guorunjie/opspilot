# 开源核心演示：快速开始

这是 Apache-2.0 授权的早期离线药房 Demo，全部经营数据均为合成数据。它不是完整 Foundation，也不能操作真实门店。

## 从源码启动

需要 Node.js 24 或更高版本，以及 Git。下载依赖需要网络；安装完成后的 Demo 操作和模拟回读不访问真实平台。

```sh
git clone https://github.com/guorunjie/opspilot.git
cd opspilot
npm ci
npm test
npm start
```

保留默认安装脚本，以下载 Electron 运行时。当前锁定 Electron 42.7.0 和 electron-builder 26.8.1。Windows 本机完整依赖安装和 32 项测试已通过；这不等于全新机器、macOS 或生产环境验收。

## 完成一次经营演示

1. 点击“运行演示诊断”，查看今日重点，展开建议依据。
2. 点击“查看跟价预览”，核对商品、原价、目标价格、成本和估算毛利率。估算毛利不等于实际利润；成本未知不能当作零成本。
3. 核对无误后，勾选“我已核对本次商品、目标价格和毛利，仅确认模拟操作。”，点击“确认本次预览”。
4. 选择演示场景，再点击“执行模拟操作”。提交后还不能判断成功。
5. 点击“核对模拟平台结果”，查看每项目标价格和回读价格，以及验证结果和复盘。
6. 点击“复位演示”并确认，可回到初始合成数据。取消复位会保留当前记录。

当前仅有一个合成商品可以执行价格操作。成本缺失与库存详情是只读说明，活动机会尚未实现；不要把三个详情卡理解为三类业务都已打通。

## 四种场景

| 场景 | 可以观察到什么 |
| --- | --- |
| 正常提交 | 提交后等待回读，逐项匹配后才显示模拟验证通过 |
| 提交后响应丢失 | 不重复提交，通过模拟回读确认目标状态 |
| 回读价格不一致 | 明确显示不一致，不报告成功 |
| 首次回读不可用，结果未知 | 首次显示 UNKNOWN；“再次核对（不重复提交）”仅读取，不重新执行 |

最后一种场景的第二次回读由合成夹具确定性恢复；真实平台不保证下次检查能够恢复。所有模拟验证均不代表真实平台验收。

## 重启与数据

会话保存在本地 SQLite。重启恢复已保存的预览、确认和执行记录，不会自动执行。已有确认以只读记录展示，不代表新的授权。演示复位清除当前合成会话，不操作真实门店数据。

Windows 数据位于用户的 `AppData/Roaming/opspilot-open-core/offline-demo`。卸载候选安装版保留该目录。演示存档无效时停止加载并保留原记录；不要为了启动成功而直接删除存档。

Demo 不读取真实账号凭据、不启动生产调度、未接入生产 Connector。当前恢复保障覆盖本地模拟状态，不是生产连接器的分布式恢复保证。

## Windows 打包与反馈

开发者可使用 `npm run desktop:dist:win` 构建安装包，输出位于 `dist/core`。应用名称为“OpsPilot Open Core Demo”，与旧版 OpsPilot 区分；默认创建桌面和开始菜单快捷方式。构建命令不自动发布。

候选包尚未签名，不要绕过系统安全提示。macOS 打包命令为 `npm run desktop:dist:mac`，须在相应环境构建和验证；存在命令不代表已完成适配。正式下载资产及其验证状态以 GitHub Releases 为准。
